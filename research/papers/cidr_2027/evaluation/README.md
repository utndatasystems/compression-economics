# CIDR 2027 evaluation

This directory will contain deterministic consumers of raw JSONL results:
schema validation, aggregate and block-level summaries, confidence intervals,
plots, and the generated findings report. Evaluation code must not launch
experiments or contain hand-copied benchmark values.

Exploratory CIDR notebooks are in `notebooks/`. Focused tests belong in `tests/`. Generated tables, plots, and reports belong
beneath `artifacts/papers/cidr-2027/derived/`; only manuscript-ready copies are
placed in the manuscript inclusion directories.
