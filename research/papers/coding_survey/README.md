# Coding for LLM-based compression survey

`manuscript/` is the Overleaf LaTeX project, linked as a Git submodule to its
separate GitHub repository. Keep survey-specific experiments and analysis beside
the manuscript in this directory; put reusable coder implementations in `src/`.

After cloning this repository, fetch the manuscript with:

```bash
git submodule update --init research/papers/coding_survey/manuscript
```
