
Equation~\ref{eq:factorization} directly gives the compression boundary:
ignoring finite-coder and metadata overhead, predictive coding compresses
relative to raw bytes if and only if
\begin{equation}
    \frac{L(x)}{N}
    <
    8\,\frac{\bytes{\operatorname{decode}(x)}}{N}.
    \label{eq:compression-boundary}
\end{equation}
